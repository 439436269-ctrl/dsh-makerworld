# 模型发布文案模板(填空即用)

> 用法:复制各段,替换 `〈…〉` 占位。**描述为富文本,禁止 Markdown 语法**(不要 `**`、`#`、`-` 列表)。

## 标题(≤50 字)

```
〈产品名〉 · 〈一句核心特征〉 · 〈适龄/场景〉
```

示例:`婴儿汉诺塔 · PETG底座三柱 + 叠套圆盘(0岁+)亲子益智玩具`
结构:品类 + 材料/结构亮点 + 人群/场景。

## 描述(分段录入,每段一行,Enter 分段)

```
段1 定位:给 〈月龄/人群〉 的〈产品〉。〈是什么〉+〈几个组件〉+〈锻炼什么能力〉。
段2 打印:适配 〈床尺寸/机型〉:〈尺寸关键值〉。〈轻量化/免支撑/免AMS 等卖点〉。〈材料〉皆可。
段3 装配:〈装配参数〉,〈手感描述〉;〈安全设计要点〉,〈谁陪玩〉。
段4 参数:层高 〈x mm〉,墙 〈n〉 圈,稀疏填充 〈n%〉,〈摆放方式〉。
段5 安全+开源:〈安全边界提示〉。〈源文件/衍生件说明〉。
段6 收尾:欢迎打印反馈~
```

## 标签(逐个 Enter,8-10 个)

```
〈产品名〉、〈类目词 如 益智玩具〉、〈玩法词 如 叠叠乐〉、
〈人群词 如 婴儿玩具/亲子玩具〉、〈材料词 如 PETG〉、〈近义词1〉、〈近义词2〉
```

原则:第一个=产品大名;覆盖"用户会搜什么";中英词各来一个(如 petg)。

## 分类

输入关键词选最贴近子类;无完美匹配时选「其他XX和游戏」类,不硬凑误导项。

## 许可证(必须问用户,三选一预设)

| 预设 | 改编分享 | 商用 | 再分发 | 适用 |
|---|---|---|---|---|
| 完全开源(用户选过) | 是 | 是 | 是 | 欢迎社区任意用 |
| CC 风格(推荐默认) | 是 | 否 | 否 | 可改进不可商用 |
| 保留所有权利 | 否 | 否 | 否 | 仅下载打印 |

## 封面与图

- 封面:**第一张实拍**(4:3,点"4:3 封面"→ filechooser → upload → 裁剪"提交")
- 实物图区(≥3 张,必填):多角度实拍
- 模型图片区:渲染图(≤20MB)
